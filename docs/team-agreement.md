## Цель MVP

Небольшое, но полностью работающее приложение, которое можно показать на интервью
и покрыть тестами одну функцию с понятным результатом.

## Обязательный объём

1. Страница «О нас»: описание приложения, имена/GitHub-логины участников и краткий вклад каждого.
2. Каталог: карточки товаров — название, категория, цена, кнопка «В корзину».
3. Корзина: добавление, увеличение количества, уменьшение (не ниже 1), удаление, общая стоимость.
4. Промокод `SALE10`: скидка 10%, неизвестный код не применяется, повторный ввод не накапливает скидку.
5. Функция для unit-тестов: расчёт корзины (сумма до скидки, размер скидки, итог).
6. Деплой приложения по публичной ссылке.

## Процесс работы

- Доска: GitHub Projects. Статусы: Todo, In Progress, In Review, Done.
- Ветки: chore/, docs/, feature/, fix/, test/, submission/.
- Коммиты: feat: ..., fix: ..., test: ..., chore: ..., docs: ...
- PR: маленькие, из своей ветки в main. В описании — что сделано, как проверить, какую задачу закрывает.
- Ревью: второй участник смотрит код и оставляет хотя бы один содержательный комментарий.
- Конфликты: не удаляем чужие изменения. Разрешаем вместе, после — npm test и npm run build.
- Перед пушем: npm run format && npm run lint && npm test — всё должно быть зелёным.

## Экраны и навигация

- Приложение — SPA с хеш-роутингом: #/about, #/catalog, #/cart.
- При загрузке открывается #/about.
- Общий каркас: header (меню, счётчик корзины) и footer (логины).
- «О нас»: «О проекте» + две карточки участников.
- «Каталог»: сетка карточек, кнопка «В корзину».
- «Корзина»: отдельный экран, строки, +/−, удаление, итог, промокод.
- Кнопка «Оформить заказ» не добавляется.
